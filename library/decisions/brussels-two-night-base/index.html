布鲁塞尔由未选分支升为两晚 mini-base

这条判断不属于某一次旅行；每一天只通过稳定 ID 引用它。

判断状态生效中创建时间 2026-09-04

判断

布鲁塞尔在 2026-09-21 至 2026-09-23 作为两晚 base，承担安特卫普无行李日游的跳板与南北铁路枢纽，并提供一个大广场清晨窗口。

理由

新 baseline 需要一个在阿姆斯特丹与布鲁日之间的落脚点，而布鲁塞尔是唯一同时满足三个条件的城市：南下与东行的铁路枢纽、到安特卫普四十余分钟的日游距离、以及车站到核心机位仅数百米的极低摩擦。它的价值主要是功能性的，摄影上只有一个完整窗口，因此不应按摄影城市的密度去安排。

依据

没有外部依据，属于判断

需要重新评估的条件

没有触发条件

本记录 supersede 了 decision/ghent-brussels-flex-day。在旧 baseline 中布鲁塞尔是 09-25 的可选半日分支，问题被表述为“要不要多去一个城市”；在新 baseline 中它是承重结构，问题不再存在。

住宿位置的硬性要求

必须步行可达 Bruxelles-Central。理由不是便利而是安全：09-21 抵达在傍晚之后，且携带全部行李与器材，而 Bruxelles-Midi 周边是全程夜间风险最高的区域。Bruxelles-Central 距大广场约三百四十米，是全程车站摩擦最低的城市。

订房前必须确认二十四小时前台或明确的深夜入住流程。这不是偏好，是 09-21 抵达时间决定的前置条件。

摄影定位

只有 09-23 上午一个完整窗口，09-22 全天在安特卫普。大广场四面封闭，九点前几乎无人，是全程最容易拍到空的世界级广场的地方；晨光要到八点后才越过屋顶打进广场，因此“空的蓝灰色广场”与“金光打在市政厅塔尖”是两种不同画面。不要试图在这一个上午塞满——当天下午要转场，晚上是布鲁日的核心蓝调。
