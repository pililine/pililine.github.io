2026-09-27 改为科隆到巴黎直达并退役 Bruxelles-Midi 换乘模型

这条判断不属于某一次旅行；每一天只通过稳定 ID 引用它。

判断状态生效中创建时间 2026-09-04

判断

2026-09-27 使用 Köln Hbf 到 Paris Gare du Nord 的直达国际列车，取代旧的布鲁日经 Bruxelles-Midi 到巴黎的两段换乘；europe-2026-bruxelles-midi-buffer-minimum 随之退役而非重定向。

理由

旧约束的语义是 Bruxelles-Midi 站内换乘缓冲，用于吸收 Eurostar 检票提前三十分钟关闭的风险。新路线不存在这次换乘，该语义在新 baseline 中没有对应物，机械地把它指向直达班次会制造一个看似仍在保护什么、实际已无对象的约束。退役并保留 provenance 比重定向更诚实。

依据

koln-paris-eurostar-direct

需要重新评估的条件

koln-paris-eurostar-direct

结构性收益

旧 baseline 中 09-27 是全程最脆弱的一天：清晨拍完布鲁日立刻退房、赶本地 IC 到 Bruxelles-Midi、在检票关闭前完成国际列车衔接，任何一环延误都会连锁。新 baseline 中它降级为普通转场日——零换乘，清晨改为可选，抵达巴黎反而更早。

同时，比利时罢工敞口从 09-27 转移到了 09-25：09-27 是德法直达，不属 SNCB 罢工范围；09-25 则同时涉及比利时国内段、跨国段与当晚入住不可退的住宿。

保留但停用

europe-2026-bruxelles-midi-buffer-minimum 置为 inactive 而非删除，其 subject 与 target 继续指向已 cancelled 的 transport/2026-09-27-brussels-paris。这样既不参与当前路线的断言求值，又保住了引用完整性与历史可追溯性。

当前 Constraint.status 只有 active 与 inactive 两个取值，无法区分“因路线变更而作废”与“临时停用”。该表达力缺口已登记为 schema follow-up，本轮不解冻。

booking 状态

transport/2026-09-27-cologne-paris 目前为 unbooked。住宿变更交接文件中记录的候选班次未购票、也未确认在周日运行，因此不写入 canonical。europe-2026-international-train-reference 只断言该 Operation 存在，不断言已购票。
