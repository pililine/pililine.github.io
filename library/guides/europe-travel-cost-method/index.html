Europe travel cost method

  • europe
  • cost-planning
  • governance

成本规划把价格分成住宿、城际交通、市内交通、门票、餐饮、摄影附加交通、机场交通和杂项，并为每类保留币种与估算状态。

  1. 先固定会改变 Trip Structure 或关键摄影窗口的住宿与动态定价交通，再处理可替代门票。
  2. 住宿评价要把位置价值纳入成本：低光机位后的安全返回、换城拖箱和行李寄存可以合理地高于单纯最低房价。
  3. 对不需要提前购买的本地交通和现场项目，只记录规划假设，不把它们升级为 NOW。
  4. 估算、已报价和已支付金额必须分开；每个金额保留明确 currency，不使用无语义数字。
  5. 分类合计、总预算和预算差异从 canonical category values 派生，不在多个页面保存第二份总数。
  6. 未来由 Operations 系统管理实际预订与支付；本 Guide 不扩展成住宿、票务或预算平台。

具体 Trip 的金额只放在该 Trip long-form 或未来授权的 Operations owner 中，本 Guide 不携带某一年、某城市或某物业价格。
