Film and literary location reference method

  • reference
  • governance
  • culture

电影、文学与流行文化取景地的收录方法。核心原则是：

Library knowledge ≠ itinerary commitment.

一个地点进入 Library，不得因此自动改变任何 TripDay、Operation、Constraint、Decision 或 ShootSession。

收录判据

按顺序回答，任一为否即降级或不收录：

  1. 该地点是否真实存在且可定位到稳定坐标？
  2. 它的文化关联是否具体（明确作品与明确场景），而不是泛泛的「曾出现在电影里」？
  3. 除去文化关联之外，它是否仍有可观察的物理特征（立面、动线、光线、尺度）？
  4. 它是否已被某个既有 Place 覆盖？若是，应叠加参考而不是新建近重复实体。

只满足第 1、2 条的，作为纯参考保存，不进入任何行程讨论。

叠加而非复制

取景地几乎总是落在既有城市知识之上。正确做法是把电影关联写进该地点自身的 Place，或写进一份组织性 Guide，而不是再造一套与既有路线平行的时间表。若发现同一条傍晚路线被电影主题重写了一遍，那就是重复真相，应当合并回既有 owner。

与行程的关系

  • 顺路：地点落在既有动线可视范围内，可作为提示，不占用独立时段。
  • 需独立时段：必须先确认该日仍有余量，并作为一次显式选择，而不是附加。
  • 不成立：与既有硬性节点、光线窗口或体力预算冲突时，保留在 Library 即可。

营业时间、开放日与拍摄规则属于会变化的外部规则，若确实影响计划，应由 ResearchFact 承担，而不是写进 Place 正文当作永久事实。
