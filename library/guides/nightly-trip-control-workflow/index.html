Nightly trip control workflow

  • trip-control
  • contingency
  • review

每晚用一个短控制循环决定第二天，而不是把候选方案预先写成确定时间轴。

  1. 检查天气，决定户外、室内或恢复优先级。
  2. 从 Place 坐标和日期重新计算次日 astronomy；只在运行时使用结果，不把 sunrise、sunset、civil twilight 或衍生摄影窗口写回内容文件。
  3. 如果次日有铁路或机场节点，检查承运人状态、站台或终点信息以及备用方案。
  4. 检查已选场馆的临时闭馆、罢工、预约与器材规则；ResearchFact 仍 pending 时按其 blocks / affects 语义处理。
  5. 对活动、街拍或天气 options，只选择一个可执行分支；未选分支继续保留 trigger、rationale 和 Plan B，不创建 active Session / Operation。
  6. 完成 travel-photo-backup-workflow，并确认下一次低光拍摄后的回程与器材收纳路径。

Action bucket 继续从 Operations、Facts、Constraints 与 Decision 状态派生；本 Guide 不建立第二套 NOW / NEXT / WAIT 清单。
