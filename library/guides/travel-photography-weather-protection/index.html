旅行摄影天气防护

天气

防雨的目标是让器材在天气变化中可继续工作，同时避免因急着擦拭而造成二次损伤。

  1. 为机身镜头和背包分别准备简单雨罩；外层防护失效时应先撤到遮挡处，而不是继续暴露器材。
  2. 带小型折伞和防风外层，根据风力选择；拍摄时保持一只手能控制器材与脚下位置。
  3. 准备至少 3 块干燥镜头布并分开存放，湿布不要继续反复擦镜片。
  4. 从冷湿室外进入温暖室内前先把相机装入包内缓慢回温；出现凝露时不要立即拆镜头或强行擦拭内部表面。
  5. 雨停后的反光条件属于摄影机会，但是否创建或调整 Session 仍由 weather-contingency-workflow 和当次 Trip 决定。

本 Guide 不保存任何城市天气概率、具体预报或某次旅行的雨天选项。
