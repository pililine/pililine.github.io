天气变化应对流程

天气

天气分支的目标是保护不可替代条件，而不是把全部 Plan B 同时塞进 timeline。

  1. 前一晚先判断次日是户外优先还是室内优先。
  2. 只有已经选择的方案创建 active ShootSession / Operation；其余保留为 option、trigger 和 rationale。
  3. 雨停后优先利用仍湿的地面和开始透光的天空；具体站位仍引用 PhotographySpot。
  4. 室内外对调时，先确认票务与开放 Fact，不得把候选场馆假定为已预约。
  5. 阴天但无明显反光时优先街拍、室内建筑、黑白与材质细节；登高、需要强方向光的花园和日出日落目标可延后。
  6. 场馆中断时只激活一个已确认可用的替代；互换表是决策素材，不是多条并行 timeline。

Rotterdam 是高抗雨案例：rotterdam-centraal-interior、markthal-rotterdam、kubuswoningen 的有遮挡动线和 depot-boijmans-exterior 的柔和镜面条件可以保留现代建筑主题，而不需要虚构一个新行程。
